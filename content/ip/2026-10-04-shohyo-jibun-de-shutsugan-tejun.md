## 結論

商標は、弁理士やオンラインサービスに頼まなくても、会社が自分で出願できます。流れは「事前調査 → 願書の作成 → 出願 → 審査 → 登録料の納付」です。特許庁に納める料金は、1区分なら出願料12,000円と登録料32,900円です（2026年10月4日時点、特許庁の料金一覧で確認）。

手間がかかるのは出願そのものよりも、出願前の調査と、電子出願を選ぶ場合の初回の準備です。この記事では、特許庁の案内ページに沿って、順番に整理します。

## 全体の流れ

1. 似た商標がすでにないかを調べる（J-PlatPat）
2. 商標を使う商品・サービス（指定商品・指定役務）と区分を決める
3. 願書（商標登録願）を作る
4. 書面またはインターネットで出願し、出願料を納める
5. 審査の結果を待つ
6. 登録査定が届いたら、登録料を納める

特許庁の案内によると、出願すれば必ず登録されるわけではありません。商標審査官の審査を通過したものだけが登録を受けられます。また、原則として出願日から2、3週間程度たつと、出願内容が一般に公開されます（出願公開）。

## 手順1：J-PlatPatで先に調べる

特許庁は、出願前に先行商標調査を行うことが大切だと案内しています。他人が同一または類似の商標（マークが類似し、かつ商品・役務が類似するもの）をすでに登録していると、登録を受けられないだけでなく、無断で使うと商標権の侵害になる可能性があるためです。

調査には、特許情報プラットフォーム「J-PlatPat」の「商標検索」を使います。特許庁の案内ページが紹介している検索方法は次の2つです。

- **称呼（類似検索）**：読み方が類似する可能性のある商標を広く探す。
- **商標（検索用）**：入力した文字を含む商標を探す。

文字で探すときの注意点も案内されています。

- ひらがな・カタカナ・英字は別の文字として扱われます。カタカナで検索すると、ひらがなや英字の商標は出てきません。
- 「？」を使うと、前方一致・後方一致・中間一致の検索ができます。
- 検索の仕方によっては網羅的に検索できていない可能性があるため、検索項目やキーワードを変えて検索することが勧められています。
- 情報の反映までに時間差が生じることがあります。

類似する商品・役務には同じ「類似群コード」が付いています。絞り込みたいときは、類似群コードを組み合わせると便利だと案内されています。

## 手順2：指定商品・指定役務と区分を決める

願書には、マーク（商標）と、その商標を使う商品・サービス（指定商品・指定役務）を書きます。指定商品・指定役務を分野別に分類したものが「区分」で、第1類から第45類まであります。

料金は区分数で決まります。特許庁の案内ページの例では、「自動車並びにその部品及び附属品」は第12類、「自動車の修理又は整備」は第37類で、両方を指定すると2区分になります。

指定商品・指定役務は、正しい区分のもとで、内容が明確な表示で書く必要があります。不明確な場合などは拒絶理由の対象になります。特許庁で採択可能な表示と類似群コードは、J-PlatPatの「商品・役務名検索」で調べられます。

## 手順3：出願の方法を選ぶ（書面か、インターネットか）

出願の方法は、書類で出す方法と、インターネットを用いる方法の2つです。

| 項目 | 書面で出願 | インターネットで出願 |
|---|---|---|
| 準備するもの | 願書の様式、特許印紙 | Windows 11 のパソコン、電子証明書、インターネット出願ソフト |
| 出願料の納め方 | 特許印紙を願書に貼る（収入印紙は使えない） | 電子現金納付、口座振替、予納、現金納付、クレジットカード納付の5種類から選ぶ |
| 電子化手数料 | 2,400円＋（800円×書面のページ数）が別にかかる | かからない |
| 提出先 | 特許庁の窓口に持参、または郵送 | 自社のパソコンから送信 |

### 書面で出願する場合

特許庁の案内による手順は次のとおりです。

1. 商標登録願の様式をダウンロードし、「商標登録出願書類の書き方ガイド」を参照して作成する。A4判（縦長）の白紙に印刷する。
2. 特許印紙を購入し、指定の箇所に貼る。収入印紙では手続きできません。
3. 特許庁の出願受付窓口に持参する（平日9時から17時まで）か、特許庁長官あてに郵送する。郵送は書留・簡易書留郵便・特定記録郵便で、宛名面の余白に「商標登録願 在中」と書く。
4. 出願日から数週間後に送られてくる払込用紙で、電子化手数料を納める。

### インターネットで出願する場合（法人）

電子出願ソフトサポートサイトの「法人の方へ」は、準備を7つのステップで案内しています（2026年10月4日時点で確認）。

1. **パソコンの準備**：インターネット出願ソフトは Windows にのみ対応しています。サポート対象は64ビット版の Windows 11 Home と Windows 11 Pro（日本語）です。Windows 10 は、2026年2月22日以降オンライン手続ができなくなっています。
2. **電子証明書の準備**：手続者が法人の場合、使えるのは法務省の電子認証登記所が発行する電子証明書だけです。ファイルタイプとICカードタイプがあります。発行手数料は法務省のページで確認します。
3. **出願ソフトの入手**：サポートサイトからダウンロード請求をします。メールアドレスが必要です。
4. **インストール**：管理者権限が必要です。
5. **申請人利用登録**：「識別番号」と「電子証明書」の組み合わせを特許庁に登録します。書面による事前手続は不要で、オンラインで登録できます。
6. **申請書類の作成**
7. **電子出願**

電子証明書には注意点があります。サポートサイトによると、法務省の商業登記電子証明書に導入されるリモート署名方式は、インターネット出願ソフトでは2027年3月頃まで利用できません。これから電子証明書を取る会社は、取得前にサポートサイトの案内を確認してください。

願書の作成には、特許庁の「さくっと書類作成」が使えます。ブラウザの画面に入力するだけで電子出願用の一部の書類を作れるもので、商標登録願も対象です。押さえておく点は次のとおりです。

- 対応ブラウザは Windows 版の Google Chrome と Microsoft Edge です。
- さくっと書類作成からは出願できません。作った書類は、インターネット出願ソフトで特許庁へ送ります。
- 代理人による手続、優先権主張、分割出願などには対応していません。
- 手続上の是非はチェックされません。内容が正しいかどうかは、自分で確かめる必要があります。

## 料金（2026年10月4日時点、特許庁の料金一覧で確認）

特許庁の「産業財産権関係料金一覧」（更新日 2026年4月6日）に記載されている料金です。

| 項目 | 金額 | 1区分の場合 |
|---|---|---|
| 商標登録出願 | 3,400円＋（区分数×8,600円） | 12,000円 |
| 商標登録料 | 区分数×32,900円 | 32,900円 |
| 商標登録料の分納額（前期・後期の各回） | 区分数×17,200円 | 17,200円 |
| 電子化手数料（書面で出願した場合） | 2,400円＋（800円×書面のページ数） | ページ数による |

オンラインサービスを使う場合の手数料との比べ方は、[商標出願のオンラインサービスを選ぶ前に](../ip/shohyo-online-service-checklist.html)で整理しています。

## 出願のあと：審査と登録料の納付

### 審査の着手までにかかる期間

特許庁は「商標審査着手状況（審査未着手案件）」で、審査着手までの期間の目安を審査室ごとに公表しています。2026年10月1日更新の表では、令和8年10月から令和9年1月に出願する案件の目安は次のとおりです。

| 審査室 | 主な担当区分（類） | 審査着手までの期間（目安） |
|---|---|---|
| 化学 | 1〜5 | 6か月〜8か月 |
| 食品 | 29〜33 | 6か月〜8か月 |
| 機械 | 6〜13、19 | 7か月〜9か月 |
| 雑貨繊維 | 14〜18、20〜28、34 | 7か月〜9か月 |
| 産業役務 | 35〜40 | 7か月〜9か月 |
| 一般役務 | 41〜45 | 8か月〜10か月 |

これは着手時期の目安で、保証するものではないと明記されています。ページは約2か月ごとに更新されます。

### 拒絶理由通知が来た場合

登録できない理由が見つかると、拒絶理由が通知されます。特許庁の案内では、出願人は意見書を提出して意見を述べたり、手続補正書を提出して指定商品・指定役務を補正したりすることで、拒絶理由を解消できることがあります。

### 登録査定が届いたら30日以内に対応する

登録査定が届いても、手続きはまだ終わっていません。特許庁の「商標の登録査定を受け取った方へ」は、30日以内に対応するよう案内しています。納付方法を決め、商標登録料納付書を作成して特許庁長官あてに提出します。一括で納めるか、前期・後期に分けて納めるか（分割納付）は、このときに選びます。

## 運営者の視点

当媒体の運営者である Blue Aegis株式会社は、2026年8月18日に、オンラインサービスを使わず、特許庁の電子出願ソフトから自社の商標を出願しました（標準文字、第42類の1区分、出願料12,000円）。

この経験と上の一次資料から、当媒体は次のように考えています。出願を1件だけ予定している会社は、電子出願の準備にかかる手間と、書面で出す場合の電子化手数料を比べて決めるのがよいと考えます。理由は、電子出願にはパソコンの条件、電子証明書、申請人利用登録という初回の準備があり、1件のためだけに整えるには負担が大きい場合があるためです。一方、商標や他の手続きを今後も続けて行う会社は、最初に電子出願の環境を整える意味があると考えます。準備は初回だけで済み、電子出願なら書面で出す場合の電子化手数料がかからないためです。

また、自分で出願する場合に時間をかけるべきなのは、願書の作成よりも事前調査と指定商品・指定役務の選び方だと考えます。さくっと書類作成は手続上の是非をチェックしないと明記されており、様式が整っていても、内容の判断は出願人に残るためです。

## まとめ

- 商標は自分で出願できる。流れは、調査 → 区分の決定 → 願書作成 → 出願 → 審査 → 登録料の納付。
- 出願前に J-PlatPat で、称呼と文字の両方から類似の商標を調べる。
- 書面で出すと、電子化手数料（2,400円＋800円×ページ数）が別にかかる。電子出願は Windows 11 と、法人の場合は電子認証登記所の電子証明書が必要。
- 1区分の特許庁料金は、出願料12,000円、登録料32,900円（2026年10月4日時点）。
- 審査着手までの目安は、審査室により6か月から10か月（2026年10月1日更新の表）。登録査定が届いたら30日以内に対応する。

類似かどうかの判断や区分の選び方に迷う場合は、弁理士にご相談ください。
