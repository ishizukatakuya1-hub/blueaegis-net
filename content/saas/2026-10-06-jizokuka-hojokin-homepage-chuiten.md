## 結論

小規模事業者持続化補助金（一般型・通常枠）は、ホームページの制作や更新にも使えます。ただし、第20回公募の公募要領（第8版、2026年7月21日）には、ホームページを目的にする会社が先に知っておくべき条件が4つあります。

1. **ホームページの経費（ウェブサイト関連費）だけでは申請できない。** ほかの経費と一緒に申請する必要があります。
2. **ウェブサイト関連費の補助金交付申請額は、上限30万円（税込）。** 補助金全体の上限（50万円）より低く決められています。
3. **交付決定日より前に発注・契約・支払いをしたものは対象外。** 採択通知が届いただけでは始められません。
4. **補助事業の期間内に公開して使い始めなかったホームページは対象外。**

第20回の申請受付は2026年11月5日（木）から12月15日（火）17:00まで、採択発表は2027年3月頃の予定です。交付決定はそのさらに後になるため、**ホームページを急いで公開したい会社には向きません**。

以下は、2026年10月6日時点で、補助金事務局の公式サイトと公募要領を確認した内容です。

## 対象になる会社

公募要領では、業種ごとに「常時使用する従業員の数」で小規模事業者かどうかを判断します。

| 業種 | 常時使用する従業員の数 |
|---|---|
| 商業・サービス業（宿泊業・娯楽業を除く） | 5人以下 |
| サービス業のうち宿泊業・娯楽業 | 20人以下 |
| 製造業その他 | 20人以下 |

会社役員は「常時使用する従業員」に含まれません。株式会社や合同会社は対象になりうる一方、一般社団法人や医療法人などは対象になりません。また、申請の時点で開業していない創業予定者も対象外です。

## 補助率と上限額

| 項目 | 内容 |
|---|---|
| 補助率 | 2/3（賃金引上げ特例のうち赤字事業者は3/4） |
| 補助上限 | 50万円 |
| インボイス特例 | 50万円上乗せ |
| 賃金引上げ特例 | 150万円上乗せ |
| 両方の特例の要件を満たす場合 | 200万円上乗せ |

特例にはそれぞれ要件があり、公募要領は、特例を希望して要件を1つでも満たさなかった場合、上乗せ分だけでなく補助金の全体が交付されないとしています。

補助金は後払いです。先に自社で全額を支払い、実績報告のあとに補助金を受け取ります。

## ホームページに使うときの条件

ホームページの制作費は、8つある対象経費のうち「ウェブサイト関連費」に入ります。公募要領の定義は、販路開拓等を行うためのウェブサイトやECサイト、システム等の開発、構築、更新、改修、運用をするために要する経費です。

### 単独では申請できず、上限は30万円

公募要領は、ウェブサイト関連費について次のように定めています。

- ウェブサイト関連費のみによる申請はできない。必ず、ほかの経費と一緒に申請する。
- ウェブサイト関連費の補助金交付申請額の上限は30万円（税込）。

補助率が2/3の場合、経費が45万円のときに補助金が30万円になる計算です。制作費がそれを超えても、ウェブサイト関連費として受け取れる補助金は増えません。

条件は公募回によって変わることがあります。過去の公募回について書かれた解説の数字ではなく、申請する回の公募要領で確かめてください。

### 対象になる経費、ならない経費

公募要領の経費例のうち、ホームページに関係するものを抜き出しました。

| 対象となる経費例 | 対象とならない経費例 |
|---|---|
| 商品販売のためのウェブサイト作成や更新 | 補助事業期間内に運用に至らなかったホームページ・ランディングページ |
| 効果や作業内容が明確なウェブサイトのSEO対策 | ウェブサイトおよびシステムに関連するコンサルティング、アドバイス費用 |
| 商品販売のためのウェブサイトに掲載する宣材写真の制作費用 | ウェブサイトに使用する画像等における被写体や商品の購入に係る費用 |
| ウェブサイトに掲載する商品・サービスを販売するための画像や動画作成費用 | 有料配信する動画の制作費 |

この補助金は販路開拓の取組を支援するものです。公募要領は、広報費について「単なる会社のPRや営業活動に活用される広報費」を対象外としています。ホームページも、どの商品・サービスを、誰に売るためのものかを経営計画に書けることが前提になります。

### ドメイン・サーバーの費用

第20回の公募要領には、ドメインの取得費やレンタルサーバーの利用料を名指しした記載がありません。一方で、対象外の経費として「電話代、インターネット利用料金等の通信費」が挙がっています。公募要領が別紙としている「参考資料」と「申請時によくあるご質問」は、2026年10月6日時点で、商工会議所地区の公式サイトでは準備中です。ドメインやサーバーの費用を計上したい場合は、申請前に、地域の商工会・商工会議所か補助金事務局に確認してください。

確認の結果にかかわらず、ドメインとサーバーは補助事業が終わったあとも毎年支払いが続きます。補助金を前提にせず、会社が自分で払い続けられる金額のものを選ぶ必要があります。ドメインの選び方は[法人のドメインは .co.jp から](../saas/houjin-domain-cojp-erabikata.html)、メールまで含めた設定は[会社のメールを独自ドメインにする手順](../saas/dokuji-domain-mail-setup.html)にまとめました。

## 契約と支払いで守ること

- **交付決定日より前に発注・契約・支払いをしない。** 公募要領は、補助金の対象となる経費の発注・契約・支出行為は「補助金交付決定通知書」に記載された交付決定日から可能としています。採択通知書だけでは始められません。前払いも対象外です。
- **支払いは銀行振込が原則。** 1取引10万円（税抜き）を超える現金払いは対象外です。クレジットカード払いは会社の名義で、補助事業の期間内に引き落としまで終わっている必要があります。
- **1件50万円（税込）を超える発注は、2者以上から見積を取る。**
- **期間内に公開して使う。** 公募要領は、ホームページで受注システムを作ったものの、補助事業の終了までに公開して販路開拓の取組を行っていない場合を、対象外の例に挙げています。
- **キャッシュバックに乗らない。** 購入額の一部や全額を払い戻して自己負担を減らす、または無償にする販売方法は、補助金交付の目的に反する行為とみなされます。
- **50万円（税抜き）以上で作ったホームページは「処分制限財産」になる。** 一定の期間（通常は取得日から5年間）、目的外の使用や廃棄などが制限されることがあります。補助事業の目的を遂行するために必要な改良や機能強化は、ここでいう処分には当たりません。

## 日程（第20回、2026年10月6日時点）

| 項目 | 日付 |
|---|---|
| 申請受付開始 | 2026年11月5日（木） |
| 事業支援計画書（様式4）発行の受付締切 | 2026年12月4日（金） |
| 申請受付締切 | 2026年12月15日（火）17:00 |
| 採択発表（予定） | 2027年3月頃 |
| 見積書等の提出期限 | 2028年2月29日（火） |
| 補助事業の実施期限 | 2028年3月31日（金） |
| 実績報告書の提出期限 | 2028年4月10日（月） |

公募要領には、予定は変更する場合があると書かれています。

申請は電子申請システムだけで受け付けており、郵送はできません。GビズIDプライム（またはGビズIDメンバー）のアカウントが必要で、公募要領は取得に数週間程度かかるとしています。

もう1つ、地域の商工会・商工会議所から「事業支援計画書（様式4）」の発行を受ける必要があります。この受付は12月4日が締切で、公募要領は、締切以降の発行依頼はいかなる理由があってもできないとしています。社外の代理人だけで相談や発行依頼をすることもできません。実質的な締切は12月4日と考えてください。

交付決定は、採択後に見積書等を提出し、事務局の審査を経てからです。公募要領は、見積書を速やかに出した場合でも採択発表からおおむね1〜2か月かかる場合があるとしています。

## 運営者の視点

当媒体は、ホームページを作ることだけが目的なら、この補助金を前提に計画を組まないほうがよいと考えます。理由は3つです。ウェブサイト関連費だけでは申請できないこと。受け取れる補助金がウェブサイト関連費では30万円までであること。そして、第20回の日程では、発注できるようになるのが早くても2027年の春以降になることです。新しく作るホームページをこの補助金に合わせると、交付決定まで着手できず、公開の時期がそれだけ遅くなります。

反対に、展示会への出展や機械の導入など、ほかの販路開拓の取組を計画していて、それとあわせてホームページを作り直す会社は、申請の条件に合う可能性があります。ただし、この補助金には審査があり、不採択になる場合もあります。

運営者の Blue Aegis株式会社は、2026年8月12日に会社のドメインを申し込みました。ドメインは会社が続くかぎり持ち続けるものなので、補助金の日程とは切り離して、必要になった時点で会社の名義で取っておくことをおすすめします。

## まとめ

- ホームページの経費（ウェブサイト関連費）だけでは申請できない。補助金交付申請額の上限は30万円（税込）。
- 交付決定日より前の発注・契約・支払いは対象外。期間内に公開して使い始めることも必要。
- 第20回の申請受付は2026年11月5日から12月15日17:00まで。様式4の発行受付は12月4日まで。
- GビズIDプライムの取得には数週間程度かかる。

補助金の要件や日程は変わることがあります。申請の前に、必ず補助金事務局の公式サイトで最新の公募要領をご確認ください。旧IT導入補助金にあたる制度は、[会計ソフトを「デジタル化・AI導入補助金2026」で導入する前に知っておくこと](../saas/digital-ai-hojokin-kaikei-soft.html)で扱っています。
