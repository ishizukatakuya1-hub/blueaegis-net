## 改善の進め方（週次モニタリング）

1. 計測を見る（取れる範囲で）：GA4（ページ別の表示回数・エンゲージメント・反響イベント・流入元・端末）、Search Console（検索クエリ・表示回数・CTR・掲載順位・インデックス状況）、Cloudflare Web Analytics。
2. 仮説を立てて小さく直す：title/description、見出しの言葉選び（実際の検索クエリに寄せる）、問い合わせボタンの位置・文言、内部リンク、表示速度（画像サイズ）、スマホ表示の崩れ。
3. 1回の変更は小さく、何をなぜ変えたかを下の「改善ログ」に1行で残す（効果を次回比べるため）。
4. `node tools/build.js` が通ることを確認してから main に push（GitHub Pages に自動デプロイ）。変更したページは IndexNow で通知する。
5. 大きな変更（構成の入れ替え、新しいページ、写真の差し替え、上の「守ること」に触れうる表現）は公開せず、提案としてユーザーに報告する。
