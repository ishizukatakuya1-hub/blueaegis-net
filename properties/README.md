## 書いてはいけない・守ること（ユーザー指示）

- Blue Aegis株式会社は物件オーナーではない。「物件オーナー」と書かない。表記は「〜の運営に携わるBlue Aegis株式会社が作成しています」「運営：Blue Aegis株式会社」。オーナー名は出さない。
- 築年数は両サイトとも載せない。
- ヒルズ・セイキュウは賃料・共益費などの金額を載せない（管理会社への問い合わせに誘導）。
- 景品表示法を意識し、断定・最上級を避ける（「いません」→「ほとんどいません」、「安全」→「安心していただけます」等）。
- 室内のフリー素材写真を物件の写真として見せない。イメージ写真には「写真はイメージです」。
- 夜道の安心の訴求でアルバイト帰りに触れない。
- サンディココの浸水想定（想定最大規模で0.5m未満）があるので、災害面の安全は訴求しない。ヒルズの「津波浸水想定区域外」は重ねるハザードマップで確認済み。
- サンディココ1階のパーソナルトレーニングジム（ttTB）は「別途契約が必要」の注記を外さない。
- 数値・施設・距離・日付を足すときは一次資料で確認する。確認できないことは書かない。
- 管理会社：ヒルズ＝エイブルネットワーク静岡南店（株式会社山晃住宅）、サンディココ＝ピタットハウス長野駅前店（株式会社東邦不動産プラザ、n.ekimae@tohoplaza.co.jp／026-225-5555。2026-10-17 伊東様のご依頼で長野北店から変更）。連絡先を変えるときはユーザーに確認。
- 地図・経路リンクは住所ではなく座標で指定（ヒルズ 34.9666432,138.4293669／サンディココ 36.6607919,138.2036965）。住所検索だとピンがずれる。

## 改善の進め方（週次モニタリング）

1. 計測を見る（取れる範囲で）：GA4（ページ別の表示回数・エンゲージメント・反響イベント・流入元・端末）、Search Console（検索クエリ・表示回数・CTR・掲載順位・インデックス状況）、Cloudflare Web Analytics。
2. 仮説を立てて小さく直す：title/description、見出しの言葉選び（実際の検索クエリに寄せる）、問い合わせボタンの位置・文言、内部リンク、表示速度（画像サイズ）、スマホ表示の崩れ。
3. 1回の変更は小さく、何をなぜ変えたかを下の「改善ログ」に1行で残す（効果を次回比べるため）。
4. `node tools/build.js` が通ることを確認してから main に push（GitHub Pages に自動デプロイ）。変更したページは IndexNow で通知する。
5. 大きな変更（構成の入れ替え、新しいページ、写真の差し替え、上の「守ること」に触れうる表現）は公開せず、提案としてユーザーに報告する。
